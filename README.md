## 📌 1. What is 42?

**42** is an innovative programming school with no teachers and no traditional lectures.
It is built on a **peer-to-peer learning model**, where students grow by working on real projects and collaborating with each other.

The curriculum is designed to develop:

* 🧠 **Deep problem-solving skills**
* ⚙️ **Low-level systems understanding**
* 🔁 **Autonomous learning**
* 🤝 **Peer evaluation and collaboration**

Instead of studying theory first, you learn by **building from day one**.

This repository gathers all the projects completed during the **Common Core**.

Each project is:

* 📂 organized in its own directory
* 📄 fully implemented in source code
* 🧪 tested according to 42 standards
